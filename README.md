# FleetDash - Infotact Solutions

**High-Throughput Event-Driven Fleet Telemetry Dashboard**

FleetDash is a web application designed to monitor vehicle fleets, process telemetry events, visualize operational data, and display alerts through a responsive dashboard.

## Project Objectives

- Build a responsive fleet monitoring interface.
- Develop backend APIs for vehicle and telemetry data.
- Integrate MongoDB for persistent storage.
- Support real-time dashboard updates.
- Visualize vehicle locations, telemetry trends, and alerts.
- Test functionality and performance and document results.

## Planned Technology Stack

- Frontend: React, Vite, JavaScript
- UI: Tailwind CSS
- Charts: Recharts
- Maps: Leaflet
- Backend: Node.js and Express
- Real-time communication: Socket.IO
- Database: MongoDB
- Testing: Automated tests and telemetry load testing
- Version control: Git and GitHub

## Planned Features

1. Fleet overview and vehicle status.
2. Vehicle search, filtering, and details.
3. Telemetry ingestion and historical records.
4. Live dashboard updates.
5. Vehicle location visualization.
6. Analytics and operational alerts.
7. Input validation, error handling, and performance testing.

## Project Structure

- `frontend/` - React frontend
- `backend/` - API, database, and real-time services
- `simulator/` - Telemetry event simulator
- `tests/` - Application and performance tests
- `docs/` - Project documentation
